## path hazards

### H1: domain directory rename

**what changed**: `src/domain/` renamed to `src/domain.objects/`
- `src/domain/constants.ts` → `src/domain.objects/constants.ts`
- `src/domain/objects/*.ts` → `src/domain.objects/*.ts` (flattened)

**why it may break**: all imports via `@src/domain` would fail (118 type errors initially)

**fix applied**:
- created `src/domain.ts` re-export file for backward compatibility
- updated `src/domain.objects/index.ts` to export all domain objects

**verification**: `rhx git.repo.test --what types` passes
