# nitpick.1: Inconsistent path redaction for snapshot stability

The snapshot rule emphasizes using redacted paths for stability in visual diffs (as shown in the rule's positive examples and the redactPaths helper in this file). However, not all snapshots apply redaction: --help and no-command cases snapshot raw output that may contain machine-specific paths (e.g. temp dirs, /home paths, or command paths), while plan cases and error cases do apply redactPaths. This risks snapshot drift, test failures across environments, and reduced value for PR visual diffs.
